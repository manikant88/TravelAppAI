# Travel supplier access and budget caveats

Research date: 4 September 2026. Bounded preliminary research for an India domestic pilot with external booking handoffs; this is not vendor selection or an accepted budget.

## Findings

- **Booking.com:** Demand API access requires being a Managed Affiliate Partner, a signed agreement and Partner Centre access through an account manager. Public documentation supports a search-and-redirect integration, but does not establish that a new small pilot will be approved or state a public fee in the reviewed pages. Do not assume that ordinary affiliate registration guarantees API access. [Prerequisites](https://developers.booking.com/demand/docs/getting-started/prerequisites), [integration types](https://developers.booking.com/demand/docs).
- **Skyscanner:** Its current Travel API application page specifies commercial selection and a minimum of 100,000 monthly active users; it directs other potential partners to widgets and affiliate links. A 50–100-group monthly pilot should not rely on obtaining this API. That is an eligibility inference, not a pricing estimate. [Official application criteria](https://www.partners.skyscanner.net/contact/travel-api).
- **Viator:** The affiliate page says signup and additional API access carry no fees. Basic access is available upon affiliate registration; higher tiers require qualification. The access comparison distinguishes basic content/schedules from real-time availability, which requires approved Full Access and certification. It supports external booking handoffs, but India destination coverage and useful local activity selection still need a practical audit. Free access alone does not establish adequate coverage or freshness. [Affiliate program](https://partnerresources.viator.com/travel-commerce/affiliate/), [access comparison](https://partnerresources.viator.com/travel-commerce/levels-of-access/).
- **Amadeus:** Indexed official documentation describes a test subset, production real-time data, free monthly quotas followed by metered charges, and Self-Service coverage excluding low-cost carriers. However, directly opening the public pricing and FAQ paths during this research redirected to a JavaScript homepage without readable pricing/onboarding information. Therefore those indexed descriptions are insufficient to confirm current production availability or an executable price quote. Obtain current confirmation before selecting it; do not promise comprehensive Indian domestic flight coverage from the old Self-Service description. [Indexed pricing guide](https://admin.developers.amadeus.com/self-service/apis-docs/guides/developer-guides/pricing/), [indexed FAQ](https://admin.developers.amadeus.com/self-service/apis-docs/guides/developer-guides/faq/), [current pricing route](https://developers.amadeus.com/pricing).

## Budget implications

Reserve a provisional supplier allowance, but do not claim it guarantees supplier access. Fees, minimum commitments, permitted display and storage, search-to-booking limits, handoff support, Indian low-cost airline coverage, and rail/bus coverage need written or directly documented confirmation from shortlisted providers. No rail or bus API commercial terms were verified in this bounded research.

Recommendation: first verify production access and representative routes/destinations; then calculate usage from expected searches and refreshes. If access is unavailable within the ceiling, narrow launch coverage explicitly or obtain a revised ceiling. Do not silently replace current supplier facts with synthetic results or AI-invented prices. Basic affiliate link access is not equivalent to permission to retrieve and display current inventory.

No accounts were created, providers contacted, subscriptions purchased, or application behavior changed.
